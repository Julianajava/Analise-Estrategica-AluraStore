# Analise-Estrategica-AluraStore
Análise estratégica de desempenho de lojas utilizando Python, Pandas e Matplotlib.
<h1 align="center">📊 Análise Estratégica - Alura Store</h1>

<p align="center">
Projeto de análise de dados desenvolvido com Python para apoiar uma decisão estratégica de negócio.
</p>

<hr>

<h2>🎯 Objetivo</h2>
<p>
Avaliar o desempenho de quatro lojas e recomendar qual unidade deve ser vendida, considerando:
</p>

<ul>
<li>Faturamento total</li>
<li>Categorias mais vendidas</li>
<li>Média de avaliação dos clientes</li>
<li>Produtos mais e menos vendidos</li>
<li>Custo médio de frete</li>
</ul>

<hr>

<h2>🧠 Conclusão Estratégica</h2>

<p>
Com base nas análises realizadas, a <strong>Loja 4</strong> é a melhor candidata para venda.
</p>

<p>
Ela apresentou:
</p>

<ul>
<li>Menor faturamento total</li>
<li>Desempenho inferior em vendas</li>
<li>Custo de frete elevado</li>
<li>Menor competitividade geral</li>
</ul>

<p>
A decisão é fundamentada em dados quantitativos e visualizações gráficas.
</p>
